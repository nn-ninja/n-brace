**I encourage now to use n-brace standalone app but if you use Obsidian, the plugin still can still be helpful.**

## Accepted plugin

N-brace plugin for Obsidian has become an official plugin.
You can install it now in a standard way for plugins visiting the page [https://community.obsidian.md/plugins/n-brace](https://community.obsidian.md/plugins/n-brace). 


### BRAT installation
The old, still working way to install N-brace is to do it using BRAT plugin:
1. Install the Brat Plugin in Settings → Community plugins → Browse BRAT → push the Install button
2. Enable BRAT in Settings → Community plugins
3. Open BRAT settings and click "Add Beta plugin"
4. Enter the repository URL: nn-ninja/n-brace
5. Click "Add Plugin" and enable N-brace in your community plugins
BRAT will automatically check for updates and notify you when new versions are available.
